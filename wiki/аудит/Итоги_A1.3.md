# Контрольная точка A1.3: 14 ZIP рассмотрены, A1 ещё не закрыт

Дата: 27.09.2026. Основание — согласованный [план 0.2](../../План_аудита_оригиналов_на_согласование.md). [Индекс](Индекс_архивов_A1.3.md) содержит отдельный отчёт для каждого из 14 предоставленных архивов. Слово «рассмотрены» здесь означает **выборочное статическое исследование относящихся к защите исходников, тестов и документов**, а не полное чтение каждого ZIP, запуск оригиналов или доказательство безопасности агента.

## Разделение источников по роли

- Оригинальные кандидаты на runtime-проверку L3: [AGT](AGT_A1.3.md), [DSH](DSH_A1.3.md), [Pydantic AI](Pydantic_AI_A1.3.md), [OpenAI Agents](OpenAI_Agents_A1.3.md), [Goose](Goose_A1.3.md), [Hermes](Hermes_A1.3.md), отдельные пути [Microsoft Agent Framework](Microsoft_Agent_Framework_A1.3.md). Эти методы различаются языком, точкой контроля, режимом отказа и исполнителем; совпадение названия «approval» не делает реализации эквивалентными.
- L1 и оркестрация: [NeMo](NeMo_A1.3.md) предоставляет rails и вызовы детектора, но локальный шлюз не доказан fail-closed; [LangGraph](LangGraph_A1.3.md) даёт точку обёртки инструмента, но не готовую policy/OS sandbox; [Dify](Dify_A1.3.md) содержит модерацию, лимит и клиент внешнего sandbox, но keyword-фильтр не равен детекции prompt injection.
- Управляющая плоскость, не backend enforcement: [OpenHands](OpenHands_A1.3.md) в данном ZIP — Agent Canvas, а не исходник agent-server policy.
- Материалы для испытаний и критериев: [GenAI Red Team Lab](GenAI_Red_Team_Lab_A1.3.md) — учебные уязвимые цели и проверочный harness; [GenAI Data Security Initiative](GenAI_Data_Security_Initiative_A1.3.md) — статический сканер и формат трасс; [OWASP CheatSheetSeries](OWASP_CheatSheetSeries_A1.3.md) — рекомендации и фрагменты примеров. Их нельзя выдавать за встроенные защитные слои агента.

## Что известно по уровням нашей схемы

- **L1.** Есть варианты модерации и детектирования, в том числе требующие отдельной модели/службы. Ни один из отчётов A1.3 не доказывает end-to-end защиту нашего агента от косвенной prompt injection. Наличие разделителей в Markdown-примере не доказывает Spotlighting; работающий prompt sandwiching в нашем runtime не подтверждён.
- **L2.** Корпус даёт описания и рекомендации, но для нашей части не обнаружена проверенная локальная реализация ролевых эмбеддингов или security fine-tuning. Отсутствие подтверждения не является доказательством невозможности метода или отсутствия его во всех 14 ZIP.
- **L3.** Найдены различные authorization/approval, rate/budget и sandbox-подходы. По исходникам видны несовпадающие defaults и fail-open/partial-containment пути; отсутствие фактического эффекта запрещённого инструмента не проверялось. Прикладная проверка инструмента, контейнер и ОС-политика — разные барьеры.
- **Смежные блоки.** Прокси, коннекторы, UI-разрешения, память и трассы исследованы там, где влияют на защиту. Мы не разрабатывали ядро агента, его UI, шину или внешний сетевой шлюз.

## Открытые пробелы до перехода A1 → A2

1. **Происхождение.** ZIP названы `main`/`master`; точный commit каждого снимка по одним именам и выборочным хешам не установлен. Для проверенного permalink требуется отдельная сверка с upstream commit или честная отметка «commit неизвестен» в карточках A2. Не подменять это совпадением версии пакета.
2. **Глубина.** Исследованы выбранные исходники и тесты, не все элементы каждого архива; полный CRC/антивирусный/вредоносный аудит ZIP здесь не выполнялся. Содержимое нельзя объявлять безопасным для запуска только на основании A1.3.
3. **Исполнение.** Ни один оригинальный тест или метод из ZIP не запускался. Нет доказательств для VM, контейнера, Windows/Linux ACL, сети, модели, sandbox escape, остановки после отказа или фактической блокировки инструмента. Все такие утверждения остаются статическими гипотезами до A4.
4. **Заимствование.** [A1.2](Сверка_заимствований_A1.2.md) сверил уже заявленные копии/адаптации, но не перенёс оригинальные методы побайтно и не испытал их. Исходники DSH, LangGraph и других проектов не смешивались в новом runtime.
5. **Лицензии/зависимости.** Зафиксированы корневые лицензии выбранных ZIP; право и способ переноса конкретного фрагмента, вложенные лицензии и зависимости проверяются перед A2 по каждому выбранному файлу. Dify имеет дополнительные условия к Apache-2.0; у OWASP-материалов CC BY-SA 4.0.
6. **Метрика.** Число 14/14 означает охват архива отчётом, не процент выполнения ЧТЗ, качество метода или coverage тестов. Общий методный каталог с приоритетом переноса и решение о целевой интеграции ещё не принят.

## Контрольное решение

**A1.3 завершён по критерию «у каждого ZIP есть отчёт и названы пробелы»**. **A1 в целом пока открыт**: происхождение по commit, единый каталог кандидатов и контроль качества ссылок требуют отдельной сверки. Без неё и без отдельного перехода по согласованному плану не начинать A2, не извлекать файлы и не запускать методы. Ближайший разрешённый шаг — контрольная сверка A1: проверить 14 ссылок/хешей, собрать короткий приоритетный список оригиналов для A2 и явно отметить неподтверждённые commit/лицензии. После этого представить пользователю решение о переходе.
