# Реализованные политики: код, проверки и ограничения

Обновлено 01.10.2026 по исходникам проекта и сохранённым отчётам. Эта страница
показывает текущие результаты; новые испытания при её подготовке не выполнялись.
Пользователь предоставил расшифровку разговоров и подтвердил формат развиваемой
Wiki. [Карта методов](методы/README.md) ведёт к десяти отдельным карточкам с кодом,
источниками, учебными проверками и ограничениями.

## Что уже получилось

Есть два самостоятельных результата: собственный прототип L1/L3 с адаптациями
и частичный опыт с оригинальным AGT в Ubuntu VM. Их проверки имеют разный охват.

- Сохранённый [машинный отчёт прототипа от 25.09](../policy-gateway/test-results.json)
  сообщает о 84 Python-тестах и 16 тестах DSH-адаптера. Это синтетические события,
  лабораторные инструменты и проверки маршрута LangGraph; реальная LLM и
  ОС-песочница этим отчётом не проверены.
- [Отчёт AGT-пилота от 29.09](../labs/01-agt-budgets/Отчёт_пилота_20260929.md)
  фиксирует 16/16 оригинальных Rego-тестов, четыре ручных входа и 77/77 выбранных
  тестов обработчиков ACS. Полные журналы остаются в VM; на D: сохранён отчёт
  по наблюдавшемуся выводу. Реальный инструмент полной цепочкой ещё не блокировался
  в подтверждённом опыте.

## Что остаётся проверить

- Перенести исходные журналы из VM и сверить их SHA-256.
- Испытать реальную цепочку Guardian/SDK → OPA → инструмент, доверенные счётчики,
  настройки порогов и отказные ситуации.
- Проверить отдельный реальный NeMo-детектор: пока есть [клиент](../policy-gateway/l1/nemo_jailbreak.py#L60)
  и тесты его контракта. Эффективность модели-детектора не измерена.
- Проверить нужные методы остальных архивов; статический [аудит A1.4](аудит/Матрица_покрытия_A1.4.md)
  не заменяет испытание. L2, модельный опыт, реальный sandbox инструментов и
  интеграция в агент команды остаются открытыми.

## Оформление заметок и аудиоматериалы

Текущий формат заметки: **задача → код/оригинал → проверка → результат → ограничение**.
Ссылки относительные, пригодны для Wiki в Git; для исходников указаны функции и строки.
Полный набор наглядных примеров по прежнему плану оформляется после испытаний.
Эта страница — текущая сводка уже имеющихся результатов по новому поручению пользователя.

Из предоставленной расшифровки перенесён принцип постепенного наполнения страниц:
прикреплять к конкретному методу источник, код, небольшой тест и фактический
результат, включая неудачу. Markdown принят как достаточный формат; Confluence
и HTML не являются обязательным отдельным проектом. Каталог статей остаётся
тематическим, без графа всех ссылок внутри статей.

Обсуждение Firecracker, Docker, ресурсов GPU и моделей не подтверждает их выбор
или испытание. Новых решений о среде по записи не вводили. Личные фрагменты,
аудиофайлы и дословный транскрипт в публикуемый Wiki-комплект не включены.
