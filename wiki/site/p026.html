A1.3 — индекс последовательного аудита 14 ZIP

Этот индекс показывает глубину содержательного чтения, а не факт наличия ZIP или результат антивирусной проверки. «Частично» в A1.2 означает сверку конкретных заимствований, но не аудит всего пакета. Порядок — строго по плану 0.2. Исходные архивы остаются в C:\Users\abUser\Downloads; отчёты — на D:.

№ Пакет / ZIP Статус A1.3 Отчёт
1 AGT / agent-control-standard-integration.zip Изучены относящиеся к безопасности Rego-модули, тесты, manifest, сборка snapshot и граница host failure; runtime не проверен AGT
2 NeMo / Guardrails-develop.zip Изучены L1 и смежные rails, конфигурации, тестовые сценарии и режимы отказа; runtime/модели не проверены NeMo
3 OpenAI Agents / openai-agents-python-main.zip Изучены guardrails, порядок function tool/approval, ключевые тесты и sandbox backends; runtime не проверен OpenAI Agents
4 LangGraph / langgraph-main.zip Изучены ToolNode, перехват вызова, ошибки, interrupt/checkpointer, ключевые тесты и границы локального графа; runtime не проверен LangGraph
5 DSH / deepseek-harness-master.zip Изучены предисполнительный маршрут инструмента, approvals, presets/config, fs/process sandbox и относящиеся тесты; runtime не проверен DSH
6 Pydantic AI / pydantic-ai-main.zip Изучены filtered/approval toolsets, validate/execute, usage limits, HITL, native tools и ключевые тесты; runtime не проверен Pydantic AI
7 Microsoft Agent Framework / agent-framework-main.zip Изучены Python FIDES/approval/MCP, .NET ShellPolicy/DockerShellExecutor и выбранные тесты; runtime не проверен Microsoft Agent Framework
8 Hermes / hermes-agent-main.zip Изучены terminal approval, защищённые записи файлов, Docker/egress, website blocklist, Tirith и выбранные тесты; runtime не проверен Hermes
9 Goose / goose-main.zip Текущая копия ZIP читается (3 023 элемента); изучены инспекторы, разрешения, L1 shell scanner, egress и shell; runtime не проверен Goose
10 OpenHands / OpenHands-main.zip Изучены Agent Canvas, запуск внешнего agent-server, ключи/маршрутизация, UI permissions и Docker-граница; backend enforcement и runtime не проверены OpenHands
11 Dify / dify-main.zip Изучены input/output moderation, Redis concurrency limit, code sandbox client/Compose, SSRF proxy и выбранные тесты; runtime не проверен Dify
12 GenAI Red Team Lab / GenAI-Red-Team-Lab-main.zip Изучены назначение учебного red-team корпуса, уязвимый стенд памяти, mock agent и консервативный отчётный harness с тестами; runtime не проверен GenAI Red Team Lab
13 GenAI Data Security Initiative / GenAI-Data-Security-Initiative-main.zip Изучены 107 правил статического сканера, маршруты redaction/CI, валидатор агентных трасс и тесты; runtime/точность не проверены GenAI Data Security Initiative
14 OWASP CheatSheetSeries / CheatSheetSeries-master.zip Изучены руководства по AI agents, prompt injection, authorization, Docker и logging; код в Markdown — иллюстрации, runtime не проверен OWASP CheatSheetSeries

Текущий охват A1.3: 14/14 пакетов выборочно статически исследованы; контрольная точка и пробелы. Это не процент выполнения ЧТЗ или безопасности агента и не утверждение, что прочитан каждый элемент архивов.
