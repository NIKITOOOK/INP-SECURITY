# Вики проекта

## Открыть как документацию

[HTML-версия с боковым меню](site/index.html) — локальная сборка для обычного браузера, без сервера. Слева — разделы и карточки, справа — текст; меню сохраняется при переходах. На узком экране меню располагается сверху.

Основное содержимое — Markdown. После изменения страниц пересобрать из корня проекта в **PowerShell 7**: `./wiki/Build-Wiki.ps1`. Это только сборщик документации, не запуск политик. Используется встроенный ConvertFrom-Markdown, установка библиотек и доступ к сети не нужны.

Папка wiki/site/ — готовый статический результат, включаемый в комплект, чтобы его можно было открыть после скачивания без сборки. После правок её можно пересобрать из явного публичного манифеста public-files.json; Git не требуется. Личные журналы и исключённые оригиналы не копируются; недоступные ссылки показаны пунктирным подчёркиванием с пояснением.

## Рабочие карточки сейчас, итоговые примеры после испытаний

По последующему поручению пользователя страницы методов ведём уже сейчас и дополняем по мере работы. Markdown — основной формат; по запросу о боковой навигации добавлена локальная HTML-оболочка без сервера и Confluence. Инструкции повторения не считаются новыми результатами; частичные и неудачные проверки также остаются в Wiki.

В [плане аудита, раздел 7](../План_аудита_оригиналов_на_согласование.md) закреплён итог A4 → A5: карточки проверенных реализаций со схемой пути, конфигурацией/кодом, разрешённым, запрещённым и ошибочным входами, фактическим решением и наблюдаемым эффектом, логами и инструкцией повторения. По уточнению пользователя итоговые наглядные примеры оформляем после завершения всех запланированных испытаний; во время опытов сохраняем отчёты и доказательства.

Сейчас отчёт AGT подтверждает отдельную политику и обработчики, но не фактическую остановку инструмента полной цепочкой. Полные журналы последнего опыта находятся в VM и пока не экспортированы. Непроведённые испытания и иллюстрации не представлять как подтверждённые результаты.
