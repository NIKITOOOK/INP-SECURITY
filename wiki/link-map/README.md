# Исходники карты ссылок

template.html — оформление без карточек; cards.json — очищенные карточки прежней карты. Полные внешние разговоры и исходник из Downloads не используются. Новые ссылки сборщик добавляет из тематического каталога Wiki и реестра статусов.

Из корня проекта в PowerShell 7: ./wiki/Build-LinkMap.ps1.
Результат: [готовая карта](../../references/rendered/IMP-2026-links-wiki-updated.html).

Для просмотра готовой карты PowerShell и Git не нужны. Скачайте весь проект, распакуйте с сохранением папок и откройте HTML. Для пересборки Wiki используется wiki/public-files.json: новые публичные документы необходимо явно добавлять в этот список. Частные журналы и оригинальные архивы туда не включать.

Карточка означает наличие источника в подборке, а не независимую проверку содержания. Удалённые посторонние материалы не возвращать. HTML-фрагменты карточек являются доверенным оформлением проекта; чужой HTML автоматически не импортировать.
