Собственное повторное применение L1 в графе, см. [README прототипа](../../policy-gateway/README.md); не побайтовая копия внешнего output rail.

## Принцип и код

Результат инструмента рассматривается как новый недоверенный вход: получает метки либо заменяется безопасным сообщением до возврата из графа.

[result_gate](../../policy-gateway/langgraph_adapter/runtime.py#L271).

## Небольшой опыт в VM

Только **ГОСТЬ Ubuntu**, после [проверки условий](README.md#повторение-проверок). Модель не нужна: планировщик и инструменты лабораторные. Это инструкция повторения существующих тестов, не выполненная новая лабораторная.

1. В госте откройте каталог `policy-gateway` проверенной копии проекта и активируйте заранее подготовленное Python-окружение.
2. Прочитайте сценарии в [исходном тесте](../../policy-gateway/test_langgraph_end_to_end.py), затем запускайте по одному:

```bash
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_tool_output_is_checked_by_l1_before_graph_returns
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_oversized_tool_output_is_replaced_before_return
```

3. Сохраните команды, полный stdout/stderr и коды возврата отдельно для каждого случая. Заполните [протокол](README.md#протокол-одного-опыта).

**Ожидаемое по assertions теста:** Инъекционный текст получает `prompt_injection_suspected` и `untrusted`. Результат длиной 20 001 символ заменяется `Tool output blocked by input policy`; лабораторный инструмент к этому моменту уже был вызван. При успехе каждого запуска unittest выводит `OK`, код возврата 0; внутреннее решение проверяется assertions, но не обязательно печатается.

**Фактическое:** есть общий сохранённый отчёт прототипа; нового гостевого вывода этих двух команд пока нет. Не подставлять ожидаемое в фактическое.

## Ограничение и следующий шаг

Проверка результата не предотвращает совершённое действие и не откатывает его. Детекция произвольных вредоносных инструкций не доказана.

Проверить полный цикл обработки результата реальной моделью после отдельного испытания самого метода.
