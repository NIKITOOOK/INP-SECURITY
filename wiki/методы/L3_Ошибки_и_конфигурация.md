## Статус и происхождение

Есть реализация и сценарии прототипа. Сохранённый [отчёт 25.09](../../policy-gateway/test-results.json) сообщает об успешном наборе тестов; новый запуск этой карточки в VM не выполнен. Это не статус «оригинальный метод полностью испытан».

Собственные ограничения прототипа. Их нельзя автоматически приписывать ACS: режимы отказа оригинала разобраны в [аудите AGT](../аудит/AGT_A1.3.md).

## Принцип и код

Ошибка оценки должна остановить модельный вызов; путь вызова от модели не может изменить политику даже при расширении обычного списка операций.

[validate](../../policy-gateway/engine.py#L71), [evaluate](../../policy-gateway/langgraph_adapter/adapter.py#L118), [Engine._decide](../../policy-gateway/engine.py#L367).

## Небольшой опыт в VM

Только **ГОСТЬ Ubuntu**, после [проверки условий](README.md#повторение-проверок). Модель не нужна: планировщик и инструменты лабораторные. Это инструкция повторения существующих тестов, не выполненная новая лабораторная.

1. В госте откройте каталог `policy-gateway` проверенной копии проекта и активируйте заранее подготовленное Python-окружение.
2. Прочитайте сценарии в [исходном тесте](../../policy-gateway/test_langgraph_end_to_end.py), затем запускайте по одному:

```bash
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_c13_policy_hook_exception_fails_closed
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_c14_model_requested_policy_change_is_unconditionally_denied
```

3. Сохраните команды, полный stdout/stderr и коды возврата отдельно для каждого случая. Заполните [протокол](README.md#протокол-одного-опыта).

**Ожидаемое по assertions теста:** Исключение policy hook даёт `POLICY_EVALUATION_FAILED`; запрос `policy.modify` — `N05_POLICY_INTEGRITY`. В обоих опытах лабораторный инструмент не вызывается. При успехе каждого запуска unittest выводит `OK`, код возврата 0; внутреннее решение проверяется assertions, но не обязательно печатается.

**Фактическое:** есть общий сохранённый отчёт прототипа; нового гостевого вывода этих двух команд пока нет. Не подставлять ожидаемое в фактическое.

## Ограничение и следующий шаг

Это ограничения прикладного пути. ACL/WDAC и запрет записи в конфигурацию произвольным процессом не установлены этими тестами.

Отдельно проверить защиту файла политики и режимы отказа полной цепочки; не смешивать их с проверкой одного hook.
