## Статус и происхождение

Есть реализация и сценарии прототипа. Сохранённый [отчёт 25.09](../../policy-gateway/test-results.json) сообщает об успешном наборе тестов; новый запуск этой карточки в VM не выполнен. Это не статус «оригинальный метод полностью испытан».

Оконный лимит — собственная логика. Бюджет — ограниченная Python-адаптация AGT, не оригинальный Rego: [notice](../../policy-gateway/third_party/AGT_POLICY_NOTICE.md), [сверка A1.2](../аудит/Сверка_заимствований_A1.2.md). Оригинал рассматривается [отдельно](AGT_Оригинальный_бюджет.md).

## Принцип и код

## Небольшой опыт в VM

Только **ГОСТЬ Ubuntu**, после [проверки условий](README.md#повторение-проверок). Модель не нужна: планировщик и инструменты лабораторные. Это инструкция повторения существующих тестов, не выполненная новая лабораторная.

1. В госте откройте каталог `policy-gateway` проверенной копии проекта и активируйте заранее подготовленное Python-окружение.
2. Прочитайте сценарии в [исходном тесте](../../policy-gateway/test_langgraph_end_to_end.py), затем запускайте по одному:

```bash
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_c10_rate_limit_blocks_sixth_call_in_same_graph_session
python -m unittest -v test_langgraph_end_to_end.LangGraphEndToEndTests.test_c10_cumulative_budget_blocks_third_graph_call
```

3. Сохраните команды, полный stdout/stderr и коды возврата отдельно для каждого случая. Заполните [протокол](README.md#протокол-одного-опыта).

**Ожидаемое по assertions теста:** В оконном опыте первые пять вызовов разрешены, шестой запрещён; при накопительном бюджете 2 третий вызов блокируется. Это два разных опыта. При успехе каждого запуска unittest выводит `OK`, код возврата 0; внутреннее решение проверяется assertions, но не обязательно печатается.

**Фактическое:** есть общий сохранённый отчёт прототипа; нового гостевого вывода этих двух команд пока нет. Не подставлять ожидаемое в фактическое.

## Ограничение и следующий шаг

Счётчики хранятся в памяти процесса и учитывают выданные разрешения, а не подтверждённые внешние эффекты. Перезапуск и распределённый учёт этим тестом не проверены.

Испытать доверенный учёт реальных вызовов и сбои; не переносить результаты Python-адаптации на оригинальный AGT.
