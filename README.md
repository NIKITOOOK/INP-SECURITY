Локальная VirtualBox VM использована в пилоте, но это не доказывает изоляцию
конечного агента. Docker, Firecracker, AppLocker/AppArmor, firewall и ACL хоста
не объявлены внедрёнными защитами. Перед следующим опытом повторно проверить
состояние VM и изоляцию; настройки гипервизора выполняет пользователь.
